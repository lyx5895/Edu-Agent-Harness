# A/B 候选与训练数据规范

状态：待评审  
日期：2026-11-19  
适用范围：edu-harness 教师端的 A/B 候选、教师反馈留痕、研究整理与训练数据导出

本文从[课程教学工作台设计草案](COURSE_WORKSPACE_DESIGN.md)第11节拆出，主文档只保留与工作台流程直接相关的约束。课程、班级、任务、布置记录等概念以主文档为准。本文描述目标方案，不表示这些能力已经实现。

术语：

- **ELE（Education Last Exam）**：项目用于评测教育模型的案例集。案例按明确任务整理，例如一次出题、一次批改或一次答疑。
- **研究案例（ResearchCase）**：从一次教学任务整理出、可进入 ELE 或研究统计的记录。同一任务的候选、重试、内部复核和编辑属于同一案例，不分别计数。
- **来源组**：共享原材料、原题、答案、评分依据或互相改编而来的一组记录，划分开发集和测试集时整体处理。

## 1 目标与基本原则

A/B比较嵌入正常教学工作，教师选择、修改和使用产物时自然形成反馈。后台分别记录“选择哪个”“为什么选择”“最后改成什么”和“实际是否使用”，不将所有行为压缩成一个胜负标签。

候选展示不限学科，优先用于出题、教学活动和讲解任务；验收重点与主文档一致，放在数学和人工智能。批改和学情主要通过复核界面积累纠正记录；需要比较两份建议时，必须核对评分依据和学生证据，不以主观喜好替代正确性审定。

## 2 比较单位与输入条件

比较单位是一份明确的教学产物或其中可独立评估的部分，不是整门课程。较长产物优先比较局部，减少阅读负担。

| 场景 | 比较单位 | 教师主要判断 |
|---|---|---|
| 备课 | 一个活动、一道导入，必要时完整教案 | 目标对应、学生基础、时间安排 |
| 出题 | 一道题或一组等量练习 | 正确性、目标对应、难度与可用性 |
| 批改复核 | 同一作答的两份评分建议 | 给分、引用和理由是否合理 |
| 学情复核 | 同一批证据下的一项结论与建议 | 依据充分程度、结论范围与教学价值 |
| 讲评 | 同一问题的一段讲解 | 准确性、清晰度与本班适用性 |

生成前冻结共同任务输入，包括教师要求、学科、学生基础、资料片段、已采用产物版本、题型、数量、难度、时长、输出格式和允许读取的证据。两份候选均针对这一输入生成。比较提示词时，共同需求和资料保持一致，提示词差异单独记录。

例如，老师要求“为基础薄弱学生出一道检查定义域的基础题”，两份候选都必须满足这个要求。基础版与提升版属于不同方案，不默认形成优劣偏好对；若研究不同方案的适用性，需要另设明确任务与标签。

输入发生实质变化后建立新的比较记录，原候选保留原输入快照。不得把不同任务条件下生成的结果直接拼成偏好对。

## 3 候选展示与教师操作

界面隐藏模型名称，统一排版，随机分配A/B展示位置。随机结果固定在本次比较中，刷新和恢复任务不交换位置；后台以稳定候选ID记录反馈，不把字母当作模型身份。

主要操作为“采用A”“采用B”“两份都可用”“都不合适”“暂不比较”。采用后直接进入编辑，也可选择“结合两份修改”。采用默认不额外弹出必填评价表。

| 教师操作 | 后台记录 | 不得推导的结论 |
|---|---|---|
| 采用A或B | 本次工作选择及选中候选 | 未选中的候选必然错误或更差 |
| 两份都可用 | 两者均可接受 | 二者质量完全相同，或默认A胜出 |
| 都不合适 | 两者均被拒绝 | 两者之间存在确定胜负 |
| 暂不比较 | 跳过或尚无比较标签 | 任一候选获胜 |
| 结合两份修改 | 最终稿具有两个来源 | 最终稿等同于其中一个原候选 |

采用后可提供非必填的一行反馈：“这份更适合本次任务 / 只是选它继续修改 / 不评价”。仅明确选择“更适合本次任务”时，记录直接的比较偏好；普通采用作为工作选择，若用于后续研究应单独标为较弱的行为信号。

理由选填，提供“更贴合目标、难度更合适、更清楚、有事实错误、依据不足、其他”等标签。教师可点选相关段落、题目或评分点并补一句说明。两份都可用时，教师仍可自由选择一份继续编辑，使用选择和可接受性标签分别保存。

## 4 教师修改与最终使用记录

保存从原始候选到最终产物的完整链路：共同输入、候选A/B、工作选择、编辑版本、最终采用版本、实际使用记录。原候选不可被编辑覆盖；编辑建立新版本并记录来源，融合时同时关联两份候选。

系统计算字段或段落差异，教师可选填“修正错误、调整难度、适配本班、改进表达”等修改原因。原因缺失时保留为未知，不由系统把所有编辑解释为纠错。自动推断的修改类别另行标注，不冒充教师判断。

示例：老师选择B作为起点，修正一道题的答案，再降低第二题的难度，最后用于3班。后台分别保存工作选择、答案纠正、难度调整和布置记录；原B不能因为修改版被采用而被标记为完全正确。

教师撤回或更改选择时新增事件，导出明确标记当前有效反馈。没有编辑不证明认真审核；已采用不证明实际使用；已使用也不证明学生已经掌握。

## 5 候选生成与展示频率

首版支持相同模型生成不同候选，以及不同模型或不同提示词方案生成候选。记录具体改变的因素；为评估单一因素的影响，一次比较只改变该因素，其余任务条件保持一致。

相同模型若产生重复或近似重复候选，不强行展示无意义比较。重新生成的成本和次数计入原任务；一侧生成失败时，可先交付成功结果供教师使用，本次不形成完整比较数据。

A/B仅对适合比较的任务采样，展示比例、单日上限和教师关闭选项可配置。教师也可以主动请求第二个方案。紧急批改和风险复核优先完成工作，不强制插入比较。

记录候选生成方式、采样规则版本、抽样概率、触发方式、实际展示情况和跳过情况。主动请求与系统抽样分别统计，不能把只在部分场景收集的偏好当作所有教学任务的代表。

## 6 数据类型与训练用途

训练导出从原始记录中整理不同用途的数据，经质量检查后形成版本化数据集。

| 类型 | 记录形式 | 用途与准入要求 |
|---|---|---|
| 示范数据 | 任务输入 → 教师最终确认稿 | 学习完成任务；保留审阅状态，事实性内容按任务要求复核 |
| 偏好数据 | 同一输入 → 两个原候选及明确比较结果 | 学习教师选择标准；只将明确优劣标签导出为胜负对 |
| 修改数据 | 任务输入、原稿、真实修改要求 → 修改稿 | 学习局部修改与纠错；缺少修改要求时不伪造教师指令 |
| 核验数据 | 作答或结论、依据、教师审定 | 改进评分与证据判断；记录审定标准及分歧处理 |

“两份都可用”“都不合适”和“跳过”保留各自标签，不为适配训练格式而强行分出胜负。融合稿可在复核后作为示范或修改数据，不自动生成原A对原B的偏好关系。模型自动评价与教师评价分字段保存。

偏好适用范围包含本次学科、受众和教学目标。教学适配、表达偏好、事实正确性及实际学习效果分别记录。训练所用输入只包含原任务允许看到的材料，教师最终修改和审定结果作为目标或标签，不能倒灌到输入。

## 7 最小记录结构

| 记录 | 必要信息 |
|---|---|
| 比较任务 | task_id、comparison_id、比较单位、共同输入快照及哈希、来源组 |
| 候选 | candidate_id、关联运行与产物版本、原文、模型请求与返回标识、提示词版本、生成参数 |
| 展示 | A/B到候选ID的映射、展示时间、界面版本、触发方式与采样规则 |
| 教师反馈 | 教师标识、工作选择、明确偏好、可接受性、理由、定位片段、时间和修订关系 |
| 编辑与采用 | 父版本、融合来源、修改差异、修改原因、最终采用版本 |
| 实际使用 | 班级及课时或布置记录、实际使用的产物版本、使用状态 |
| 数据治理 | 允许的训练用途、授权状态与版本、去标识处理状态、独立审定状态 |
| 数据集导出 | 数据集版本、纳入记录、标签来源、来源分组、切分和排除原因 |

生成、反馈提交和导出均使用幂等标识。反馈绑定教师实际看到的候选版本；候选有新版本时不能静默迁移旧评价。原始调用日志与训练导出分开保存，训练导出只保留相应用途所需字段。

## 8 ELE审定与数据划分

研究记录区分教学任务、运行次数、产物版本和审定案例。同一任务的候选、重试、内部复核和编辑不分别计为独立任务。训练样本数可以大于任务数，但必须同时报告两种数量及来源组规模。

来源分组包含原材料、改写、派生题目和后续批改讲评。同一原题的候选及修改稿保持在同一来源组。精确重复先通过哈希发现，语义近似提供候选交由整理者确认。多个来源交叉衍生时，按关联来源整体检查切分，不能任意选择一个家族编号便视为独立。

教师采用表示工作偏好或可用性反馈，不自动变成正确性标签。正式benchmark案例需独立复核，保留审定标准、审定人和分歧处理。分别报告单任务能力和完整闭环表现；按来源分组冻结开发集和测试集，并记录人工介入。用来调整提示词、裁判或训练模型的材料不能再作为独立最终测试材料。

## 9 训练授权与导出

产品正常使用与训练授权分开。教师未授权训练仍可完成教学工作，相应内容在训练导出时排除。涉及学生材料时，核对该材料适用的授权范围，不能仅凭教师的产品操作认定允许训练。

学生原文、图片和模型输入在导出前进行去标识检查；稳定内部ID不等同于匿名数据。授权状态、处理状态或用途不满足条件的记录不得进入训练集。授权撤回后停止后续导出，标记已导出数据集中的相关记录，按既定数据处理流程处理，不承诺能够自动消除已经训练出的影响。

研究导出独立于教师文件导出，包含任务数、样本数、运行数、来源组数、课程数和贡献者数的定义。未设置真实贡献者身份时不推算教师人数。

## 10 实施范围

已实现（2026-11-19）：共同输入哈希与展示映射、触发方式与抽样记录、每日抽样上限；采用、明确偏好、两份都可用、都不合适、跳过分别记录，理由标签选填；撤回改选与结合两份修改；重复候选和一侧失败时不形成比较；编辑与修改原因留痕；来源分组、研究案例、独立审定与按来源组冻结切分；按课程授权的训练导出。

学生原文、学生图片及含学生原文的模型输入一律不进入训练数据；在明确未成年人材料的授权方式之前，这条规则持续适用。因此核验数据（批改、学情复核）目前全部排除，只在导出清单中计数。研究导出可继续提供，学生只以代号出现。

## 11 必须通过的场景

1. A/B共享同一任务输入；位置随机但刷新后不变，反馈准确绑定实际展示版本。
2. 采用、明确偏好、两份都可用、都不合适和跳过分别记录，普通采用不自动导出为胜负对。
3. 编辑和融合保留原候选与来源，最终采用稿、事实纠正和实际使用记录能够分别还原。
4. 一侧生成失败或两份候选重复时不强制比较；关闭A/B或达到展示上限不影响正常教学工作。
5. 相同来源的候选、修改稿与后续任务不跨训练和测试分区；标签与最终稿不能泄漏到原始任务输入。
6. 未获相应用途授权或未完成去标识处理的记录不进入训练导出，导出清单可追溯到原记录与授权版本。
7. 研究任务数不随内部调用或重试增加，同源数据切分可检查。
