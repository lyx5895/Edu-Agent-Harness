在教师页面填写班级、课程、题目、评分要求、参考答案和检查要求，点击发布，获得任务编号。独立检查题库先通过 API 准备。

结果：**通过**。

![教师发布任务与分发](../screenshots/functional-audit/02-publish-assignment.png)

### 4.3 作答判定与分级提示

提交错误作答：`平均速度等于路程乘以时间，45 × 3 = 135，所以平均速度是135千米每小时。`

作答判定：**通过**。返回 `incorrect`，策略动作是 `locate`。本次生成候选未满足格式要求，最终由固定定位模板反馈；这验证了审核与兜底分支，不应把模板当成模型原始回复。

![错误作答判定](../screenshots/functional-audit/05-wrong-answer.png)

连续提示：**未按预期完成三级提示，触发教师转介保护。** 最终一轮的操作序列中，出现连续审核失败，后续请求返回 `teacher_review`；不是正常的第三层提示。独立的真实模型脚本 `hint_ladder_escalates` 验证了三种提示动作，但并不覆盖这条先答错、再连续请求提示的完整交互路径。

![连续提示触发教师复核](../screenshots/functional-audit/06-hint-ladder-failed.png)

### 4.4 完整讲解：保留成功与未达预期两种结果

点击「请完整讲解」后，系统允许给解答。本次重复操作出现了不同结果。

**前一轮：未达预期。** 返回了“路程除以时间”的思路，但仍问学生 `45 ÷ 3 等于多少？`，没有给出最终数值。这条记录位于前一轮报告的 `07-full-explanation`，不是截图测试使用假模型造成的。

> 你刚才把平均速度的公式记错了，速度不是路程乘以时间，而是路程除以时间。平均速度表示单位时间内走过的路程，所以要用总路程 45 千米除以总时间 3 小时。请重新计算：45 ÷ 3 等于多少？算出结果后记得带上单位“千米每小时”。

![完整讲解未给出最终数值](../screenshots/functional-audit/07-full-explanation-failed.png)

**最终一轮：通过本题断言。** 明确给出了 `45 ÷ 3 = 15`，但末尾仍邀请学生重新计算。不能据此保证所有题目都会稳定得到完整解答。

> 你刚才把公式记反了，平均速度应该是路程除以时间，而不是相乘。就像你分糖果，45颗糖分给3个人，每人得到多少？用除法。所以正确算式是 45 ÷ 3 = 15。请重新计算并写出单位“千米/小时”。

![完整讲解给出计算结果](../screenshots/functional-audit/07-full-explanation.png)

### 4.5 辅助完成与独立检查

看过提示或讲解后，提交正确解答 `45 ÷ 3 = 15，平均速度是15千米每小时。`。结果：**通过**，证据类型为 `assisted_complete`，没有记成独立完成。

![辅助完成](../screenshots/functional-audit/08-assisted-completion.png)

随后开始教师检查题库中的新题：“小红步行 4 小时行了 20 千米……”并提交 `20 ÷ 4 = 5，平均速度是5千米每小时。`。结果：**通过**，证据为 `independent_model_assessed`。这是模型评分的独立检查，不能写成工具证明或已经掌握。另向独立检查发送提示请求，返回 HTTP `409`，会话版本没有增加。

## 8. 学生提示质量改进与复测

原来的“这一步依据的是什么，结果成立吗”只复述了错误，学生仍不知道如何检查。本次调整让首轮反馈先用通俗话说明必要概念，再提出一个结合题目情境的小问题，避免同时索要公式、数值和单位。

还修正了审核要求之间的冲突：首轮提示没有给出正确公式或最终数值，不应因此被拒绝。允许解释解题需要的基础概念；如果题目本身考查这个概念的定义，仍须避免直接说出答案。未通过的定位反馈在已配置可生成反馈的复核模型时，由该模型进行一次重写，之后仍接受两模型审核；没有配置时保留原模型重写和模板兜底。审计记录保存重写模型及原稿的复核意见。

本次速度题的真实页面输出是：

> 平均速度表示每小时行驶的路程。把45千米分给3小时，每小时的量应该比45大还是小？

这让学生先辨别“每小时的路程”和“总路程”的关系，再自行修正运算。没有直接告诉学生用除法或给出 15。

## 9. 学生端学习流程与界面优化

这一轮把学习中的主要内容集中为“题目 → 当前反馈 → 写下想法”，并保留原有学习记录：

- **统一发送入口**：默认回应当前追问；有待回答的问题时，可勾选“这是我的完整解答”提交整题作答。独立检查阶段直接评估作答，不走追问解释流程。
- **突出当前问题**：当前反馈单独成卡，末尾的引导问题放入“想一想”区域；完整聊天记录可在“回看学习过程”展开。
- **分开选题和学习**：选题区移到页面上方，开始或恢复会话后收起，仍可展开切换任务。
- **按状态展示操作**：练习完成后显示独立检查入口；独立检查禁用提示和完整讲解；照片待确认及教师复核时停止文字发送。
- **进度与收尾**：显示理解题意、尝试解答、修正思路、独立检查四个环节，区分借助帮助完成与独立检查通过。
- **手机布局**：导航缩为顶部区域，题目、反馈、输入按阅读顺序排列。修复了侧栏和 Gradio 样式作用域导致正文被挤窄的问题。

## 11. 作答复核工作台改版

复核页改为左侧选择作答、右侧核对详情的流程：

- 左侧显示待复核记录，支持按班级筛选和刷新；从“班级学情”点选也能直接进入对应详情。
