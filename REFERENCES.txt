v0.3 task-oriented redesign (2026-11-11)
The earlier adaptation kept course identifiers in its core. That coupling is
removed from the new default path, not merely renamed:
- harness/tasks.py: task/question/objective/rubric contracts and subject-neutral policy.
- harness/open_engine.py: per-task evidence/state/transactions/trace execution.
- harness/open_model.py: domain-neutral prompts and bounded model calls.
- harness/toolbox.py: source retrieval and abstaining verifier plugins.
- harness/gateway.py: explicit legacy/example compatibility boundary.

DeepTutor learning/policy.py and learning/teaching.py informed separation of
policy, evidence and model interpretation. OpenTutor tutor.py/orchestrator.py
informed material-aware context and post-generation checking. OATutor's
help-credit semantics remain applicable without importing its course structure.
No external agent framework, curriculum or probability estimator was vendored.

A custom task creates its own objective, grading rubric and private reference.
An independent check is generated for that objective and reviewed before it
is shown. A reference created and reviewed by the same model is not an external
answer key; outcomes are labeled model-assessed unless a verifier proves them.
Teacher corrections preserve original evidence and invalidate progression.

v0.5 teaching workflow update (2026-11-12)
Mechanism references continue to be the upstream sources listed for v0.4:
- DeepTutor: evidence-gated next-objective policy; adapted as prerequisite DAG recommendations.
- OATutor: explicit skill/step mapping and grading requirements; adapted as teacher-authored criteria.
- learnharness: measure/plan/teach/practice separation; adapted as persistent teacher followups.
These are design inspirations, not claims that upstream has identical APIs or implementations.
Local findings/implementations: global chronological memory reduction, automatic teacher equation
binding, criterion-level abstention, teacher review confirmation, due-task priority, and correction
reopening followups. No upstream code copied. No automatic mastery estimator or FSRS implemented.
